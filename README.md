# Berlin German - Web App

A web application for daily conversational German (Berlin dialect) practice designed for ADHD-friendly learning with 10-15 minute focused sessions.

## ✅ Web App is Ready!

The app has been successfully compiled and is running!

## 🚀 How to Access

**Open in your browser:**
```
http://localhost:3001
```

If it's not already running, start it with:
```bash
cd "/Users/BK/Desktop/Saïd Business Sch/Full Course/Tech Idea/berlin-german-web"
npm start
```

Your browser should automatically open to the app!

## 🎯 Features

- **3 Berlin German Dialogues** - Coffee shop, U-Bahn, bar scenarios
- **Audio Recording** - Uses your browser's microphone
- **Text-to-Speech** - German audio playback
- **Session Timer** - 10-minute break reminder
- **Progress Tracking** - Streaks, XP, badges, weekly charts
- **ADHD-Optimized** - Clean UI, large buttons

## 🎤 Microphone Access

When you first try to record, your browser will ask for microphone permission. Click "Allow".

## 📱 Works in All Browsers

Chrome, Edge, Safari, Firefox - all supported!

Enjoy learning Berlin German! 🇩🇪
